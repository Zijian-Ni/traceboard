# Traceboard — Portfolio Card Copy

## English version

### Traceboard · Agent Trace Player

**One-liner:** See what your agents actually did — drop a JSONL trace, get swimlanes, share a URL.

**Card blurb (≤60 words):**
Multi-agent runs are black boxes until you can replay them. Traceboard is a zero-backend static player for JSONL traces: swimlanes by agent, event-type filters, click-to-inspect drawer, and URL sharing via base64 hash. Built to make AI system work *legible* — to yourself, your team, and anyone evaluating your portfolio.

**Tags:** `agent-orchestration` · `observability` · `static-site` · `open-source`

**一句话：** 看清你的 Agent 到底在干什么 —— 拖入 JSONL 轨迹，立刻得到泳道图，一键分享 URL。
